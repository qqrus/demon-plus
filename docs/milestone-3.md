# Этап 3: признаки, CatBoost и MLflow

Дата: 2026-09-25. Ветка `codex/catboost-mlflow`. Python 3.12.13,
CatBoost 1.2.10, MLflow 3.16.1, pandas 2.3.3, NumPy 2.3.5.

## Результат

Общие признаки для обучения и инференса, прямой прогноз 1..30 дней,
выбор глубины CatBoost 4/6 на прежней валидации, MLflow с SQLite,
нативное сохранение модели, метаданные и проверка идентичности прогнозов после загрузки.

Выбранный запуск: `09377e9534cc4ff1ae39b1ccafa4e87d`.
Выбран CatBoost глубины 4, 300 деревьев, MAE, learning_rate=0.05, seed=42.
Финальная модель обучена до 2018-06-30; июль оценён после выбора параметров.

| Период, горизонт 30 | Модель | MAE | RMSE | Дневной WAPE | WAPE суммы |
|---|---|---:|---:|---:|---:|
| Валидация | mean_28 | 5.774 | 7.606 | 35.86% | 13.24% |
| Валидация | catboost_d4 | 5.593 | 7.646 | 34.73% | 18.23% |
| Июльский тест | mean_28 | 5.432 | 7.117 | 39.11% | 13.15% |
| Июльский тест | catboost_d4 | 5.102 | 6.766 | 36.73% | 10.19% |

Дневной тестовый WAPE уменьшился на 2.38 п.п., примерно на 6.1% относительно
baseline. Это один исторический месяц, а не доказательство стабильного превосходства.
На валидации baseline лучше по RMSE и суммарному спросу; 14-дневный WAPE
CatBoost на тесте остаётся высоким — 46.63%. Эти ограничения сохранены в README.

## Проверки

- 49 тестов проходят; полный прогон с `-W error` проверяет отсутствие предупреждений.
- ruff, форматирование, строгий mypy и pre-commit проходят.
- Изменение данных после cutoff не меняет признаки и обучающие цели.
- Признаки обучения совпадают с инференсом для одной даты.
- Реальная мини-модель сохраняется/загружается с совпадением прогнозов до 1e-12;
  повреждённый файл, неверные категории и origin раньше обучения отклоняются.
- Сквозной тест проверяет реальные записи MLflow и наличие модели в артефактах.
- Итоговый тест не вызывается внутри train; evaluate-model использует frozen selection,
  проверяет хеши входов, повторно возвращает сохранённый результат.
- График holdout просмотрен: подписи и легенда читаемы.

Первый технический запуск выполнен с более новыми NumPy/SQLAlchemy, которые
вызывали предупреждения внутри pandas/MLflow. Версии ограничены, тот же эксперимент
повторён без смены параметров, валидационные результаты совпали. Holdout до этого
не оценивался. Пробный запуск сохранён в локальном MLflow.
