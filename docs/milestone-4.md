# Этап 4: FastAPI и Streamlit MVP

Реализованы прогнозы по категориям на 7/14/30 дней, сохранение прогнозов и версий
в SQLite, расчёт запасов с поставками, строгая загрузка CSV и переобучение
с сравнением кандидата и отдельным применением. Интерфейс обращается к API;
бизнес-правила находятся в сервисном слое, а не в Streamlit.

Проверено: 67 тестов с предупреждениями как ошибками, включая реальные небольшие
CatBoost-обучения, API через TestClient и четыре раздела UI через Streamlit AppTest.
Ruff и строгий mypy проходят. Локальные API и Streamlit запущены с моделью Olist.
Браузерная визуальная проверка не завершилась: инструмент открытия вкладки вернул timeout.

Инструкция запуска и ограничения: [application.md](application.md).
