# Снимок результатов этапа 2

Сгенерировано командой `uv run --locked demon-plus baseline` на Olist v2.
Метрики относятся только к валидации, не к итоговому тесту.

- `protocol.json`: даты, категории, хеши входов/кода и версии окружения.
- `metrics.json`: полные метрики, включая разбивки.
- `eda.json`: агрегированный аудит данных.
- PNG: графики первого обучающего окна и примера валидационного прогноза.

Исходные данные: [Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
Производные отчёты и изображения в этом каталоге:
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/),
с атрибуцией Olist; обработка и визуализация выполнены в Demon Plus.
Этот каталог не содержит исходных транзакций или файлов моделей.

## Этап 3

Подкаталог `catboost` содержит снимок выбранного запуска обучения: выбор модели,
валидационные и тестовые метрики, важность признаков, отчёт и график holdout.
Параметры выбраны до оценки июльского теста. Нативная модель и подробные прогнозы
остаются локально в `artifacts`; в Git включены только небольшие результаты.
Снимок этапа 2 выше сохранён как история; его утверждение о неоценённом holdout
описывает состояние на конец этапа 2.
