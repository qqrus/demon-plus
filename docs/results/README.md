# Снимок результатов этапа 2

Сгенерировано командой `uv run --locked demon-plus baseline` на Olist v2.
Метрики относятся только к валидации, не к итоговому тесту.

- `protocol.json`: даты, категории, хеши входов/кода и версии окружения.
- `metrics.json`: полные метрики, включая разбивки.
- `eda.json`: агрегированный аудит данных.
- PNG: графики первого обучающего окна и примера валидационного прогноза.

Исходные данные: [Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
