# Этап 5: мониторинг, Docker и CI

Реализованы локальные отчёты Evidently по распределениям дневных продаж, оценка
качества сохранённых прогнозов после получения фактов, отдельные предупреждения
и экспорт HTML. Пороги data drift рассчитываются на истории до обучения;
пороги quality drift остаются явно описанной настраиваемой эвристикой.

Добавлены Dockerfile, Compose с подготовкой данных/модели и проверками готовности,
непривилегированный пользователь и отдельные тома. CI дополнен сборкой образа
и проверкой запуска API без модели. Удалённый GitHub Actions ещё не запускался.

## Локальные проверки

- 73 теста, включая API, Streamlit AppTest, стабильный и изменившийся ряд,
  ухудшение ошибки, неполные факты, дубли и разные версии моделей.
- Ruff, форматирование, строгий mypy и сборка wheel/sdist.
- Свежий Linux-контейнер: Evidently формирует HTML при режиме `-W error`.
- Compose с пустыми томами: загрузка Olist, обучение, итоговая оценка,
  успешное завершение init, healthy API и Streamlit.
- Повторный запуск использует артефакты; прогнозы, новые факты и отчёт
  сохраняются после перезапуска API.

## Проверка на реальном историческом обновлении

В отдельном Docker-демо сохранены 7-дневные прогнозы `cama_mesa_banho` со срезами
2018-06-30 и 2018-07-07. Загружены июльские факты из исходного Olist.
WAPE первого полного окна — 33.27%, второго — 113.03%; порог — 41.59%.
Получено предупреждение quality drift. Пороги data drift для июльского
28-дневного окна при этом не превышены. HTML Evidently успешно скачан через API.

Это пример работы сигналов на отдельных окнах одной категории, не новая итоговая
метрика проекта и не доказательство надёжности порогов. Benchmark этапа 3 не изменён.
